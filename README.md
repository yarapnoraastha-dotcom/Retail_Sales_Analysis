# Retail Sales Analysis 📊

## About the Project
This project focuses on analyzing retail sales data using SQL and Python. It uses SQLite for database management and Python libraries to analyze sales performance, identify trends, and generate business insights.

## Objectives
- Calculate total sales revenue.
- Identify the best-selling products.
- Analyze revenue by product category.
- Examine monthly sales trends.
- Calculate the average order value.
- Generate useful business insights from sales data.

## Technologies Used
- SQL
- SQLite
- Python
- Pandas
- Matplotlib
- Google Colab

## Database Structure
The project uses three tables:
- **Customers:** Stores customer IDs, names, and cities.
- **Products:** Stores product IDs, names, categories, and prices.
- **Orders:** Stores order IDs, customer IDs, product IDs, quantities, and order dates.

## Analysis Performed
- Created database tables and inserted sample retail data.
- Used SQL JOIN operations to combine information from multiple tables.
- Calculated total revenue and average order value.
- Analyzed product sales and customer spending.
- Compared revenue across product categories.
- Examined monthly revenue trends.

## Visualizations
- Revenue by Product Category (Bar Chart).
- Monthly Revenue Trend (Line Chart).

## Project File
`Retail_Sales_Analysis.ipynb`

## Dataset
This project uses sample retail data created directly within the notebook using SQL INSERT statements.

## Conclusion
This project demonstrates how SQL and Python can be used together to analyze retail sales data, identify sales patterns, and generate meaningful business insights.
